# Potvrzení odchodu

`ExitDialog` obnovuje cYesNoExit (100 původních bajtů): constructor `0047b1c0`, XML `0047a4e0`, enabled step `0047ac90`, destructor `00479c70`/`00479c90`, default `00479c80`, Yes/No click `00479d40`/`0047a110`, hover/leave `00479cb0`, `00479ce0`, `00479d10` a vector-length pomocnou funkci `00421520`. Moderní MenuView owns tři Bee Picture, dvě TextAnimationButton a MultilineText. Skutečný ResourceManager načítá `UI/YesNoExit.xml`. Konstruktor si zapamatuje původní polohu Yes a ukáže Bee0, skryje Bee1/Bee2; další XML load tuto původní polohu nepřepisuje.

Yes hover ukáže Bee2, No hover Bee1; leave obnoví Bee0 pouze pokud tlačítko není Pressed. Default Yes i No jen skryje dialog. Vlastní callback má argument samotného dialogu. Zde neexistují vymyšlené Enter/Escape bindings; původní odchod do Win32 ani obnovení hlavního menu ještě nejsou tímto controllerem propojené.

Step při Yes Hovered nepohybuje tlačítkem. Jinak vypočte vektor od cursoru k Yes, délku odpuzování max(0,(1−distance×0.0125f)×30), přeškáluje vektor, přičte původní polohu a odečte současnou. Následující posun omezuje na elapsed×120 a znovu použije původní normalizaci, potom přesune tlačítko i jeho potomky. Výpočty zachovávají float spill points a aktuální x87 precision. Pomocná funkce záměrně používá retained extended ratio pro X a znovu načtený float ratio pro Y, stejně jako instrukce `00421520`; Win32 source obsahuje upravitelný inline assembler, nepoužívá původní binární kód.

`analysis/text-buttons-validation.json` obsahuje obě precision contexts: 24 stromů, 14 512 stavů, 420 848 letters/sprites, 14 400 náhodných cursor/time/button pohybů a 1 060 shodných custom callbacků. Kontroluje nullable parent, default hide, všechny hover/pressed/leave větve, původní pozici, aktivaci a reference/input destructor delty. Dalších 64 GPU snímků zahrnuje přesuny, mouse press/release, Bee obrázky, víceřádkový text a původní skrytí callbackem. Všech 30 720 000 RGB pixelů a draw API volání se shoduje; po default hide jsou některé snímky úmyslně prázdné a stále se porovnávají všechny RGB bajty.

Native XML virtual factory má nezávislý recovered strom ze skutečného XML. Motion, normalizace, click/hover a owned lifetime spouštějí původní instrukce; frame/cursor/input/graphics/audio boundaries odpovídají ostatním UI scénám. Dosud nejsou ověřené fyzický vstup/audio, actual MainMenu exit a Win32 zavření, celá hra, neplatné font/XML vstupy a extrémní/infinite/NaN souřadnice/elapsed. Zdroj nepřebírá původní object/exception ABI.
