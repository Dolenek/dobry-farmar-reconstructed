# Přehození nástroje

ElasticAnimation obnovuje skutečný objekt z Farm/ElasticAnimation.xml: constructor0042c2d0, destructor0042b1a0, XML0042bce0, spuštění0042b7a0 a absoluteStep0042b280. Implementace používá vlastní Picture, resource manager a SoundManager. Dokončení přímo obnovuje appearance skutečných DigBuilding/MowBuilding/WaterSource singletonů; kind9 zobrazí předaný View.

Původní objekt má1028 bajtů. Singleton je na+238, rotationSpeed+23c, rotation+240, deset40-byte appearances na+244, speed+3d4, acceleration+3d8, MoveSound+3dc, kind+3e0, velocity+3e4, accelerationVector+3ec, position+3f4, remaining+3fc a revealView+400. Moderní layout je oddělený. Kind/reveal ani speed/acceleration nemají v původním constructoru výchozí hodnotu; nastavuje je XML nebo spuštění.

Shodné souřadnice jsou no-op. Begin vynuluje interní rotaci, ale geometrii úhlu změní až první krok. Normalizace X používá neuložený x87 koeficient, Y jeho float kopii z0065ff94. Výpočet délky/doby letu zachovává neuložené mezivýsledky podle instrukcí. Krok odečte float dt, otočí sprite a provede Eulerův posun/zrychlení. Při vypršení se objekt skryje bez dosazení cílové pozice. Unordered zbývající čas pokračuje pohybovou větví, stejně jako originál. XML reload zachovává původní retained sound reference; destructor uvolní aktuální sound a všechny appearances.

Porovnání PC53/PC24 zahrnuje1524 stavů /1354 akcí a168 celých D3D8 snímků /80 640 000 přesně shodných RGB pixelů. Ověřuje všech deset kinds, kvadranty/osy/krátké i nulové trasy, restart, přesné vypršení, zápornou/nulovou rychlost a nulové zrychlení s unordered dobou letu, XML reload a resource deltas. Tři skutečné tool upgrady mění profil a peníze, spouštějí skutečný let a dokončují jej v registrované UI scéně. Myší kliknutí na skutečný upgrade sekačky je porovnané přes celý let až po finální appearance. Stejně je vykreslené odhalení View pro kind9.

Diagnostika používá původní instrukce pouze jako referenci. Pozice a appearance/cancel rozhraní Person jsou výslovné hranice, dokud nebude propojena celá postava. Kind9 předává skutečný View, nikoli celý dosud neobnovený seed-drop worker. Sound požadavky/references jsou porovnané přes obnovený manager s dosavadním vypnutým diagnostickým backendem; audible/refill shoda se tím nevykazuje. Hodiny jsou řízené, ale render používá skutečný GameTimer a zdrojové UI krokování. Native CRT normal math a floor feature se inicializují jako v předchozích scénách; exception ABI zbývá.

Reprodukce: `cmake --build build/windows --config Release --target text-buttons-reference-test`, potom `python tools/validate_elastic_animation.py`. Metadata a kontrolní součty zapisuje `analysis/elastic-animation-validation.json`. Úplné Win32 sestavení a87/87 CTest prošly za397.22 s. Oba aktuální game-audio audity mají každý378 stavů /36 playback progress /16 pause kontrol; oba PersonSounds buildy také znovu prošly.
