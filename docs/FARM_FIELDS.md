# Pole, akce a prostorové dotazy Farm

`FarmField`, čtyři vlastní akce, `GameAction`/`ActionProcessor` a `FarmAreas` jsou sestavené ze zdrojů. Přímé PC53/PC24 porovnání s původními těly prošlo 4 460 stavy, 80 objekty, 4 224 kroky/dotazy a 128 GPU snímky / 61 440 000 přesně shodnými RGB pixely. Test propojuje skutečné pole, Sprinkle, WaterSource capacity, vodní emitter/částice a kolizní masku skutečného Warehouse. Spouštění, celý Farm controller a Person ještě nejsou hotové.

Reprodukce: `python tools/validate_farm_field.py`, případně CTest `original-farm-field`. Výstup `.local/farm-field-validation.json` obsahuje hashe zdrojů, reference, výsledky obou přesností a hranice diagnostiky. Publikovatelná metadata ukládá `tools/record_verification.py` do `analysis/farm-field-validation.json`. Všech 17 původních souborů se kontroluje před/po porovnání. Diagnostika mapuje původní EXE; zdrojová implementace jeho kód nevolá. V tomto prostředí sandbox blokuje PE loading chybou 623; diagnostické běhy probíhají mimo sandbox. Pouze referenční test má vlastní image base a vypnuté ASLR, produkční cíle toto nastavení nemají.

## Opravené odchylky a hranice

Přímé porovnání opravilo signed frame comparison při záporném animation time, mask String offset+1c, signed int stores fcu/fua/awGrowType a použití animation.length při purchase appearance. Voda/fertil mají původní clamp, sign a opakované losování absorption. Farm dry query znamená alespoň jedno suché pole, bez filtru active. Hover používá původní bod z animation.time, i když se liší od geometrie.

Tutorial větev Dead původně obsahovala chybný výklad FUN_00440350 jako FieldTip callbacku. ASM0043f268 připravuje ECX jako adresu dočasného vectoru na zásobníku; 00440350 jej uvolňuje. Zdroj nyní používá automatický zánik seznamu. Všech osm kombinací tip21/22/23 je přímo porovnaných, včetně skutečného těla destrukce prázdného seznamu a zobrazení/ukončení kroku23. Není přidán žádný náhradní tip callback.

FieldTip selection/hide a Farm indication jsou v oracle explicitní pozorování, Person queue rovněž. SeedPackage controller a neprázdný seznam v tutorial22 ještě čekají. Farm scene je ověřený StateView s původními Farm flag accessors, ne úplný Farm constructor/XML. Runtime nemá hotové herní EXE ani celý svět a tento test neprokazuje obousměrný save ani úplný playthrough.

Celá regrese prošla 79 z 80 kontrol za 702,63 s; kontrola ClickMask selhala před porovnáním, protože stará 3 MiB rezervace adresy mohla kolidovat s jinou oblastí, a přitom nechat image base00400000 volnou. Diagnostika nyní rezervuje pouze první64 KiB granule; následně prošlo všech864 mask vstupů obou přesností za34,09 s. Produkční masky se neměnily. Úplný a opakovaný JUnit jsou uchované zvlášť, sloučený záznam má80 úspěšných případů; podrobnosti `analysis/regression80-execution.json`. Obě game-audio sestavení znovu prošla378 stavy/36 playback/16 pause kontrolami.
