DOBRY FARMAR | Windows 10/11 | Portable edition

CZ: Rozbalte cely ZIP do slozky, kam muzete zapisovat.
Pokud chybi slozka Data, zkopirujte ji z vlastni ceske kopie hry vedle Hrat.cmd.
Slozka Data musi obsahovat Data.pack a cz.pack. Potom spustte Hrat.cmd.
Herni profily a nastaveni se ukladaji do slozky Saves vedle hry.

EN: Extract the entire ZIP to a writable folder.
If Data is missing, copy it from your own Czech copy of the game next to Hrat.cmd.
Data must contain Data.pack and cz.pack. Then double-click Hrat.cmd.
Game profiles and settings are saved in the Saves folder next to the game.
