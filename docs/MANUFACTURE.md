# Manufacture – obnovená výrobní scéna a propojení nákupu

Navazuje na ověřený commit `fba071c` (ProductionBuilding, Win32 Release, 63 CTest kontrol a obě game-audio sestavení). Zdrojová scéna vlastní skutečné budovy, používá skutečný BuyBuilding a HUD a prošla přímým porovnáním: **3 210 stavů, 170 GPU snímků a 81 600 000 přesně shodných RGB pixelů v PC53/PC24**. Samostatná geometrie má 49 152 porovnání, skutečné house masky/guards dalších 8 192. Celý cGame, sklad, ostatní scény a hlavní EXE zůstávají nedokončené. Přenositelný záznam vytváří `tools/record_verification.py` teprve po plné regresi a ověření současných source hashů.

Native controller má 256 bajtů: StateView 100, další MI word +64, allowed rectangle +68, forbidden rectangle vector +78 (allocator), +7c begin/+80 end/+84 capacity; šest controls +88..9c; saved upgrade enable byte +a0 (constructor jej neinicializuje); dvacet house pointers +a4..f0; count +f4; focused +f8; SelectSound +fc. Singleton je `0065f758`, vybraná/přesouvaná budova samostatný pointer `00660150`.

Constructor `00499730`, destructor `00496fa0`, scalar destructor `00497910`, XML `004979a0`. Horní controls mají parent StateView origin `+60`, houses parent moving Picture `+38`. Constructor order: current TextLine, current Picture, Build ExtendedTextAnimationButton, Destroy ExtendedAnimationButton, Upgrade ExtendedAnimationButton, TextMoney. Loads actual `UI/gameUI/Manufacture.xml`, installs callbacks, restores slots by signed UpgradeN and uint ProdTypeN, then **Build.show → Upgrade.hideTips → price.hide**. Konkrétní ECX operands `00499a89`/`00499aa2` opravily původní nepřesný přepis, který show/hide vztáhl na scénu. Při dosažení count 20 volá factory `00494390` HideTips rovněž na Upgrade `+98`; nelze tento neobvyklý případ přepsat odhadnutým skrytím Build.

Factory scan používá unsigned slot: −1 začíná na nule, ostatní hodnoty se přeinterpretují na uint. Pokud count přesně 20, vrátí null. Pro nalezený empty slot rozliší jedenáct původních typů a vytvoří skutečný ProductionBuilding. Potom count zvýší i tehdy, kdy neplatný requested slot žádný slot nenašel. `00498400` vrací nenulové pointers v slot pořadí. Toto není fronta nebo náhradní simulation.

XML child sections: CurrentBuildingPic/BuildButton/DestroyButton/UpgradeButton/UpgradeText/CurrentBuildingText. SelectSound reload overwrite bez release, DepotArea → čtyři floats. AntiDepotAreaList má neobvyklý původní lifecycle: helper `00497890` nejprve **resize** na section count s nulovými rectangles, potom `00497930` append každého Rect. První load tedy obsahuje `2*n` records. Opakovaný load zachová/truncuje dřívější první records a append nové; missing section nic nečistí. Instrukce resize/append byly přečteny zvlášť, nejde o reserve.

Manipulation guard `00493b70` volá skutečný house cursorInControls pro všech dvacet slots. Valid placement `00494a20` používá allowed containment, forbidden corner checks a obě house click-mask vectors přes `004f0510`. Rectangle/mask port je v ProductionPlacement; matrix/corner/null-mask comparison prošlo v obou přesnostech a Manufacture porovnává i skutečné house masky. Outside click `00496440` použije fixed rectangle 10/10/790/500, ignoruje masky při hledání house rectangle (`00493aa0` → `00417910`) a potlačí změnu selection v active steps 38/34/33 nebo při moving house. Left/top float spills, unspilled right a spilled bottom jsou zachovány; přesné ověření bude součástí scény.

Begin `004957c0` uloží Upgrade effective enable, zakáže Build/Destroy/Upgrade a vykoná skutečný GameMenu.suspendButtons. End `00495bd0` zapne Build, obnoví Upgrade podle saved byte, zapne Destroy a vykoná GameMenu.resumeButtons. OnEnabled `00497070` binds 208/209, refresh warehouse quantity text `004953e0` → `0049b5a0`, base View enable, každé house.refreshHover. OnDisabled `00497480` unbinds a base disable. OnShown `00497870` base View shown a focus(null,false). Absolute step `00493fd0` pouze StateView; enter-state slot je původní RET `004bd820`.

Focus `00494e70`: current Picture primary appearance daného levelu a dirty, original static UTF-16 title `00496520`, Destroy show. canUpgrade(false,true) rozhodne, zda ukázat Upgrade/price, canUpgrade(true,true) jejich enable/disable. SelectSound se hraje jen při změně nenulové selection s true flag. Invalid level má původní literal exception `bad level`. Name table zachovává původní ruské keys pro StringManager lokalizaci.

Build callback je skutečný entry `00493c60` (pokusy 00493c50/00493c70 jsou mid-function): při active tutorial dovoluje pouze step 32, HUD disable/absoluteDisable, skutečné BuyBuilding.open. Upgrade `00495fd0` dovoluje active step 34, čte cenu a Money před nulováním ceny pro step 34, unsigned subtraction se signed bit result, setLevel(next,true), focus(null,true) a focus(house,true). Destroy `00499630` blokuje active steps 38/34/48, přímo remove focused a zvýší uint awQDestroy; neotevírá domyšlený YesNo dialog.

Step `00493dd0` (unindexed) má pořadí 31 common, 32 build action, focused 38 slider arrow, 48 stock action, 34 upgrade action, 33 destroy action. Step 48 může přidat jeden input do skladu; plný sklad uvolní jedním kusem prvního available produktu ze všech 19 a přidá input. Oba transfer calls mají true/false. Step 34 nastaví price na skutečný literal `0`, zapne Upgrade a TextMoney.

Right press `00493bb0` ruší pouze moving built house přes `0049f7d0`: clear flag1, restore depth, restore saved press position s persistence, clear moving pointer, endManipulation, hide všech placement Pictures, DropSound. Pseudokód zde nesprávně označil normální vector loop jako unreachable; port vychází z instrukcí.

Remove `00498c60`: focus null, odstraní slot, reset progress/count/stop, level −1, DestroySound pouze built, disable/HideTips, deferred deletion, decrement count a pouze built demolition animation. Wrapper `00498840` a obecný `0047d0b0` používají stejnou native map `006604e4` přes `00432b20`; Source využívá obnovený ViewRegistry.requestDiscard. Demolition Picture 568B `00493310` loads `manufacture/depotExplos.xml`, parent je Manufacture, position saved house position. XML wrapper `00492f50` pouze Picture loader. AnimationEnded `00493820` queues `.\\Game\\Manufacture\\DepotExplos.cpp48`; helper `00493400` používá stejnou discard map. Source origin pro house je `.\\Game\\Manufacture\\Manufacture.cpp437`.

Zdrojový ProductionBuilding destructor drží stabilní adresu moving pointeru od constructoru: při base View teardown už nelze bezpečně virtuálně volat zanikající Manufacture service base. Jde o zachování původního přímého globálního čtení při vlastněné scene destruction. Vlastněná scene destruction a deset deferred house removals per precision mají shodné texture reference deltas a singleton/moving lifecycle.

Ověření obnoví jedenáct uložených typů, doplní slots do dvaceti a doloží přesný count gate, pak provede všechny úrovně/availability/Money selection a skutečné Upgrade callbacks. Devět nedokončených staveb odstraňuje přes skutečný Manufacture wrapper; skutečný BuyBuilding následně vytvoří a umístí dva nové houses. Celá scéna projde přes StateView entrance, mouse dispatcher, selection, outside-click ochrany 33/34/38 a skutečný built-house drag/right cancel. Destroy blokuje 38/34/48, potom skutečně odstraní dokončenou budovu a vytvoří depotExplos Picture. Jeho běžný step a transform ukončí animaci a vyvolají deferred callback; oba origin texts a teardown jsou porovnané. Pět XML reloadů dokládá resize/append i missing-section, tři neplatné requested slots původní zvýšení count bez alokace.

Opravy: constructor show/hide child targets; Focus zachovává pořadí Destroy.show → image copy/dirty/show → title set/show a price/Upgrade; azbukové keys používají Unicode escapes, protože výchozí MSVC code page bez `/utf-8` měnila raw UTF-8 literály. Rectangle extraction spotřebuje jeden separator. Native name table lookup obsahuje absolutní ADD address a right-press unindexed caller vyžaduje fixup singleton getteru `00499c90`; generátor nyní oba zaznamenává.

Diagnostika běží ve vlastním procesu s pevným 512 MiB monotonic heap, samostatně od všech 55 house scénářů, které zůstávají povinné v `original-production-houses`. Nativní atexit registrace pouze zaznamenává, protože mapovaný EXE nemá spuštěný CRT startup. Deferred STL helper má ABI adaptér; oba původní discard wrappers a controller bodies běží. Warehouse/SetMoney jsou explicitní pozorované service hranice, Farm/WareDetail diagnostické StateView bases. Sound requests/arguments se porovnávají s disabled backendem; audible world runtime není prokázaný.

```powershell
cmake --build build/windows --config Release --target text-buttons-reference-test

```

Povinné world služby mají abstract interface bez fallbacku nebo shipping fake provideru. Další práce: skutečný warehouse a jeho notifikace, kompletní Manufacture enabled-step tutorial playthrough, ostatní world controllery a cGame. Malformed XML, factory exceptions a reused-heap padding jsou neověřené. Hlavní EXE, whole-world saves, celý Squall a odinstalátor ještě nejsou dokončené.

Plná regrese: 64/64 CTest, Win32 Release, 279,91 s. Běžné a samostatné game-audio sestavení prošlo po 378 stavech / 36 playback progress / 16 pause kontrolách. Strict record ověřil všechny současné source hashe a 17 nezměněných originálů. Přenositelný report: [manufacture-validation.json](../analysis/manufacture-validation.json).
