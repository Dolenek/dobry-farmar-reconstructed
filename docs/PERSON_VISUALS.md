# Vzhled a stavové animace postavy – probíhající rekonstrukce

Navazuje na `5f741eb`, kde skutečná fronta, značky a vstup Field/SeedPackage prošly82/82 CTest. Nový `PersonVisuals` obsahuje vlastní původní appearance tabulky, Use/DiscrUse/WotInScythSign/WotSubstrate UI, zvukové reference a výběr idle/work/move/hose grafiky. Patří k dalšímu skládání skutečného Person s PersonTasks a původními akcemi, ne k náhradní herní mechanice. Celý actor constructor, chůze po trase a vykonávání práce dále zbývají.

Přímé PC53/PC24 porovnání `person-visuals` prošlo9014 stavy /8928 akcemi a40 GPU snímky /19 200 000 shodnými RGB pixely. Deset částečných/prázdných/skutečných XML reloadů zachovává původní data, retained Lid děti a zvukové reference. Vykreslená scéna obsahuje skutečné pole a skutečné značky fronty z Person XML; další snímky zobrazují UI po reloadech. Reprodukce: `python tools/validate_person_visuals.py`; CTest `original-person-visuals`. Úplná Win32 regrese prošla83/83 kontrolami bez opakování za371,54 s; oba game-audio buildy, striktní source/binary hashe i17 referenčních souborů prošly. Záznam je v `analysis/person-visuals-regression.json`; nejde o prokázání celého actor runtime.

XML0044b600 načítá skutečné Person/Person.xml:12×6 States (+298),11×6 JobStates (+dd8), StateWaterWithHose (+1828),12×6 IdleStates (+1958), moveMarkState (+2498) a MarkSize (+24c0). Original constructor0044f340 tyto prostředky vlastní; moderní komponenta sdílí skutečný FieldObject a nechává jím vlastnit čtyři UI děti. Její destructor uvolní aktuálních osm sound referencí a appearance pole před zánikem těchto View dětí, stejně jako původní Person destructor. Opakované sound XML zachovává původní retained reference.

Native směr+288 začíná2, activity+28c začíná12, hose flag+290 začíná1 a hoseFrame+2b2c začíná6. Rychlost+294 načítá atribut Speed. Zobrazená grafika se u idle/work/walk přepisuje pouze při změně texture pointeru; nepřepisují se automaticky všechny animable vlastnosti se stejnou texturou. HeightOffset se přebírá ze skutečných CarryHeightOffsets/JobHeightOffsets a FieldObject.setPosition znovu určuje hloubku.

Idle00450a30 mapuje PCarry2 přes Dig upgrade+2 a PCarry6 přes Mow upgrade+6; carry11 přebere speciální hose appearance/frame. Pro carry6 se poloha drženého obrázku zrcadlí podle invertX, pro carry10 se seed offset přičítá bez tohoto zrcadlení. Work00449ea0 mapuje job0 přes Dig level a job4 přes Mow level+4; jen přesně původní vyjmenované job stavy si ponechávají invertX. Hotspot funkce0044f1a0/0044f250/0044f2e0 rozlišují world bod, zrcadlený offset a nezrcadlený offset.

ShowDiscrete0044ee70 přijímá přesnou byte hodnotu1; ostatní hodnoty skryjí sign i discrete. Center a MaxLength se počítají ze šířky PictureOn, unsigned maximum a limitu50 v původním pořadí. Maximum−1 se i pro nulu zpracuje unsigned. Native PCC0..7 součet0044ed10 přetéká po32 bitech. Ikona je z ProductInfo.icon (+10), i pro sáček seed držený postavou. Finální Mow-level/PCC podmínka může právě zobrazenou seed ikonu znovu skrýt; tato zvláštnost zůstává zachovaná. Test obsahuje různé visible/current/maximum/carry/upgrade a přetečení součtu.

Move0044fe20 normalizuje přes float globál0065ff94, ukládá dot produkt do floatu a volí pět původních směrů na hranicích pi×(0.125,0.375,0.625,0.875). Hose0044a330 má jiná místa float spillů: X používá koeficient před uložením, Y koeficient uložený. Frame získá původním ořezáním k nule, nikoliv round/floor. Clamped acos004497e0 chytá unordered hodnotu v první x87 comparison větvi. Normální CRT acos0058106d používá sqrt((1−x)(1+x)) a fpatan; pomocník00588535 zachovává precision bity volajícího, nastaví nearest rounding a masky, poté obnoví původní CW. Zdrojová rutina obnovuje tento výpočet vlastními upravitelnými instrukcemi, nevolá původní CRT. V mapped diagnostice je skutečný CRT math mode flag00661618 dočasně1; staré neinicializované error callbacky se tím nezkoušejí.

Diagnostika výslovně používá FieldObject drawing/input base na obou stranách, původní Person XML a konkrétní animace/hotspot funkce. Celý native Person constructor ani actor absoluteProcess se tím nevykazují jako ověřené. Dig/Mow úrovně jsou povinné pozorované world hranice, native data drženého sáčku zatím dodává adaptér kind/count getterů (samotný SeedPackage má vlastní skutečné porovnání). Nastavení a nepoužité sloty, které originál nedefinuje při chybějících XML sekcích, nejsou označené za ověřené pro libovolnou recyklovanou haldu. GPU spojení s polem a skutečnými značkami, reloady a plná actor integrace pokračují.
